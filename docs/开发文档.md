## 项目概述

《城市测试》是一个基于 Vue 3 的纯前端在线测试应用，通过五行八字分析和性格测试为用户推荐适合居住的城市。

### 项目特点

- **纯前端实现**：无需后端服务器
- **响应式设计**：支持移动端和桌面端
- **本地存储**：使用 localStorage 保存用户数据
- **轻量高效**：快速加载，流畅体验

### 5. 城市推荐算法

#### 匹配算法

文件：`src/data/cities.js`

```javascript
export function calculateRecommendedCities(answers, wuxing) {
  const results = []

  for (const [cityName, cityData] of Object.entries(cities)) {
    let score = 0

    // 标签匹配
    for (const answer of answers) {
      if (cityData.tags.includes(answer.value)) {
        score += 1
      }
    }

    // 五行匹配（权重更高）
    if (wuxing && wuxing.dominant) {
      for (const wuxingElement of wuxing.dominant) {
        if (cityData.wuxing.includes(wuxingElement)) {
          score += 2
        }
      }
    }

    results.push({ name: cityName, score, data: cityData })
  }

  return results.sort((a, b) => b.score - a.score)
}
```

## 算法说明

### 五行计算算法

#### 天干地支计算

1. **年干支计算**
   - 以1984年（甲子年）为基准
   - 使用模运算计算偏移量
   - 天干周期：10年，地支周期：12年

2. **月干支计算**
   - 根据年干确定月干基数
   - 地支固定：寅、卯、辰...

3. **日干支计算**
   - 以1949年10月1日（甲子日）为基准
   - 计算日期差值
   - 天干地支周期分别为10和12

4. **时干支计算**
   - 根据日干确定时干基数
   - 地支按2小时一个计算

#### 五行属性匹配

- 天干五行：甲乙(木)、丙丁(火)、戊己(土)、庚辛(金)、壬癸(水)
- 地支五行：子亥(水)、寅卯(木)、巳午(火)、申酉(金)、辰戌丑未(土)

### 推荐算法

#### 评分规则

1. **标签匹配**：每个匹配标签加1分
2. **五行匹配**：每个匹配五行加2分（权重更高）
3. **综合评分**：将两项分数相加

#### 排序规则

按总分降序排列，分数越高表示越适合。

## 常见开发问题

### Q1: 修改代码后页面没有刷新？

**A:** 确保使用了 `npm run dev` 而不是构建版本。Vite 的 HMR 应该会自动刷新。

// 标签匹配权重

### Q5: localStorage 数据被清除怎么办？

**A:** 这是浏览器的正常行为。如需持久化存储，需要：

1. 添加后端数据库
2. 或使用 IndexedDB 替代 localStorage
3. 或提示用户定期备份

1. 图片使用懒加载
2. 减少不必要的响应式数据
3. 使用 v-show 替代 v-if（频繁切换时）
4. 路由懒加载
5. 代码分割
