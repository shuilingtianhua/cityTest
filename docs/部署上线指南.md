## 部署概述

### 什么是静态部署

本应用是纯前端应用，不依赖后端服务器。部署时只需要将构建后的静态文件（HTML、CSS、JS）放到任何支持静态文件托管的平台上即可。

### 部署流程图

```
本地开发
    ↓
npm run build (构建)
    ↓
生成 dist 目录
    ↓
上传到部署平台
    ↓
自动部署完成
    ↓
访问上线网站
```

## 方式一：Vercel 部署

### 什么是 Vercel

Vercel 是 Next.js 团队开发的云平台，专为前端项目优化，提供全球 CDN 加速，部署极其简单。

### 技术栈

- **平台**: Vercel Cloud Platform
- **构建工具**: Vite（内置支持）
- **CDN**: 全球分布式节点
- **域名**: 支持 Vercel 域名 / 自定义域名

### 部署步骤

#### 方法 A：通过 Git 自动部署（推荐）

1. **准备代码仓库**

```bash
# 如果还没有 Git 仓库，初始化一个
cd D:\桌面\test
git init
git add .
git commit -m "Initial commit"
```

2. **推送到 GitHub**

在 GitHub 创建一个新仓库，然后：

```bash
git remote add origin https://github.com/你的用户名/test.git
git branch -M main
git push -u origin main
```

3. **登录 Vercel**

访问 https://vercel.com 并登录（支持 GitHub、GitLab、Bitbucket 登录）

4. **导入项目**

- 点击 "Add New..." → "Project"
- 选择刚才推送的 GitHub 仓库
- 点击 "Import"

5. **配置项目**

```
Framework Preset: Vite (自动检测)
Root Directory: ./
Build Command: npm run build
Output Directory: dist
```

点击 "Deploy" 开始部署，等待约 1-2 分钟完成。

6. **获取网站地址**

部署成功后会显示类似：
```
https://your-project.vercel.app
```

#### 方法 B：通过 CLI 部署

1. **安装 Vercel CLI**

```bash
npm install -g vercel
```

2. **登录**

```bash
vercel login
```

3. **部署**

```bash
cd D:\桌面\test
vercel
```

按照提示操作，首次部署选择配置，后续只需运行 `vercel` 即可。

### 自动化部署

推送新代码到 GitHub 后，Vercel 会自动检测并重新部署。

### 常用命令

```bash
# 部署预览环境
vercel

# 部署生产环境
vercel --prod

# 查看部署列表
vercel list
```

## 方式二：Netlify 部署

### 什么是 Netlify

Netlify 是领先的静态网站托管平台，支持持续部署，界面友好，功能强大。

### 技术栈

- **平台**: Netlify
- **构建工具**: Vite（自动识别）
- **CDN**: 全球 CDN
- **特性**: 支持表单、函数、边缘计算

### 部署步骤

#### 方法 A：通过 Git 自动部署（推荐）

1. **准备代码仓库**

同 Vercel 方法 A

2. **登录 Netlify**

访问 https://app.netlify.com 并登录

3. **导入项目**

- 点击 "Add new site" → "Import an existing project"
- 选择 GitHub 仓库
- 点击 "Import site"

4. **配置构建设置**

```
Build command: npm run build
Publish directory: dist
```

点击 "Deploy site"

5. **获取网站地址**

```
https://random-name.netlify.app
```

#### 方法 B：通过 CLI 部署

1. **安装 Netlify CLI**

```bash
npm install -g netlify-cli
```

2. **登录**

```bash
netlify login
```

3. **构建项目**

```bash
npm run build
```

4. **部署**

```bash
netlify deploy --prod --dir=dist
```

### 配置重定向规则

在项目根目录创建 `netlify.toml`：

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

## 方式三：GitHub Pages 部署

### 什么是 GitHub Pages

GitHub 提供的免费静态网站托管服务，适合开源项目和个人博客。

### 技术栈

- **平台**: GitHub Pages
- **构建**: 手动或 Actions 自动化
- **域名**: `username.github.io/repo-name`
- **国内访问**: 速度较慢，可能需要代理

### 部署步骤

#### 方法 A：手动部署

1. **构建项目**

```bash
npm run build
```

2. **提交 dist 目录**

```bash
git add dist
git commit -m "Build"
git push
```

3. **配置 GitHub Pages**

进入仓库设置：
- Settings → Pages
- Source 选择 `Deploy from a branch`
- Branch 选择 `main` 或 `master`
- 目录选择 `/ (root)` 或 `/dist`
- 点击 Save

4. **访问网站**

```
https://你的用户名.github.io/仓库名
```

#### 方法 B：使用 GitHub Actions 自动部署（推荐）

1. **创建 `.github/workflows/deploy.yml`**

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v3

      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v2
        with:
          path: ./dist

      - name: Deploy
        id: deployment
        uses: actions/deploy-pages@v2
```

2. **配置 GitHub Pages**

Settings → Pages → Source 选择 `GitHub Actions`

3. **推送代码**

```bash
git add .
git commit -m "Add workflow"
git push
```

GitHub Actions 会自动构建并部署。

### 配置自定义域名（可选）

在 `dist` 目录创建 `CNAME` 文件：

```
your-domain.com
```

## 方式四：Cloudflare Pages 部署

### 什么是 Cloudflare Pages

Cloudflare 的静态网站托管服务，全球边缘节点，国内访问速度较好。

### 技术栈

- **平台**: Cloudflare Pages
- **CDN**: Cloudflare 全球网络
- **域名**: `pages.dev` 域名 / 自定义域名
- **优势**: 国内访问速度快，免费额度大

### 部署步骤

#### 方法 A：通过 Git 自动部署（推荐）

1. **准备代码仓库**

同上

2. **登录 Cloudflare**

访问 https://dash.cloudflare.com/ 并登录

3. **创建 Pages 项目**

- 选择 Workers & Pages → Create application
- 选择 "Connect to Git"
- 选择 GitHub 仓库并授权
- 点击 "Begin setup"

4. **配置构建设置**

```
Build command: npm run build
Build output directory: dist
```

点击 "Save and Deploy"

5. **获取网站地址**

```
https://your-project.pages.dev
```

#### 方法 B：通过 Wrangler CLI 部署

1. **安装 Wrangler**

```bash
npm install -g wrangler
```

2. **登录**

```bash
wrangler login
```

3. **部署**

```bash
cd D:\桌面\test
npm run build
wrangler pages deploy dist --project-name=your-project-name
```

## 方式五：自有服务器部署

### 适用场景

- 需要完全掌控服务器
- 有特殊安全要求
- 需要部署内网环境
- 企业级应用

### 技术栈

- **服务器**: Linux（CentOS/Ubuntu/Debian）
- **Web 服务器**: Nginx
- **反向代理**: Nginx
- **SSL**: Let's Encrypt（免费证书）

### 部署步骤

#### 1. 准备服务器

确保你有一台 Linux 服务器，并拥有 root 权限。

#### 2. 安装 Node.js

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# CentOS/RHEL
curl -fsSL https://rpm.nodesource.com/setup_18.x | sudo bash -
sudo yum install -y nodejs

# 验证安装
node --version
npm --version
```

#### 3. 安装 Nginx

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install nginx

# CentOS/RHEL
sudo yum install nginx
```

#### 4. 上传项目

```bash
# 方法 A：使用 scp
scp -r D:\桌面\test user@your-server:/var/www/

# 方法 B：使用 Git
git clone https://github.com/your-repo.git /var/www/test
```

#### 5. 构建项目

```bash
cd /var/www/test
npm install
npm run build
```

#### 6. 配置 Nginx

创建配置文件 `/etc/nginx/sites-available/test`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /var/www/test/dist;
    index index.html;

    # 处理 Vue Router 的 history 模式
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 启用 gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    # 缓存静态资源
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

创建软链接并启用：

```bash
sudo ln -s /etc/nginx/sites-available/test /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

#### 7. 配置防火墙

```bash
# Ubuntu (UFW)
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

# CentOS (Firewalld)
sudo firewall-cmd --permanent --add-service=http
sudo firewall-cmd --permanent --add-service=https
sudo firewall-cmd --reload
```

## 域名配置

### 购买域名

推荐域名注册商：
- 阿里云（万网）：https://wanwang.aliyun.com
- 腾讯云：https://dnspod.cloud.tencent.com
- Cloudflare：https://www.cloudflare.com
- Namecheap：https://www.namecheap.com

### 配置 DNS 解析

#### Vercel 域名配置

1. 在 Vercel 项目设置中添加自定义域名
2. Vercel 会提供 DNS 记录：
   ```
   CNAME  cname.vercel-dns.com
   ```
3. 在域名服务商添加对应记录

#### Netlify 域名配置

1. 在 Netlify 项目设置中添加自定义域名
2. 添加 DNS 记录：
   ```
   CNAME  your-site.netlify.app
   ```
3. 或使用 Netlify 提供的记录

#### Cloudflare Pages 域名配置

如果你使用 Cloudflare 托管域名：

1. 在 Cloudflare Pages 设置中添加自定义域名
2. 自动配置 DNS 记录
3. 无需手动配置

#### 自有服务器域名配置

添加 A 记录指向服务器 IP：
```
A  @  你的服务器IP
```

## HTTPS 配置

### 免费 SSL 证书

#### Let's Encrypt（推荐）

适用于自有服务器部署：

1. **安装 Certbot**

```bash
# Ubuntu/Debian
sudo apt-get install certbot python3-certbot-nginx

# CentOS/RHEL
sudo yum install certbot python3-certbot-nginx
```

2. **获取证书**

```bash
sudo certbot --nginx -d your-domain.com
```

3. **自动续期**

```bash
sudo certbot renew --dry-run
```

Certbot 会自动配置 Nginx 使用 HTTPS。

#### 平台自带的 HTTPS

- **Vercel**: 自动提供 HTTPS
- **Netlify**: 自动提供 HTTPS
- **GitHub Pages**: 自动提供 HTTPS
- **Cloudflare Pages**: 自动提供 HTTPS

无需手动配置！

## 常见问题

### Q1: 部署后页面空白怎么办？

**A:** 检查以下几点：

1. **路由模式问题**
   - 确保使用了 `createWebHistory()`
   - 配置了重定向规则（Nginx: `try_files`）
   - Vercel/Netlify 自动配置

2. **构建问题**
   ```bash
   npm run build
   # 检查 dist 目录是否生成
   ```

3. **控制台错误**
   - 打开浏览器开发者工具
   - 查看 Console 和 Network 标签
   - 检查是否有 404 错误

---

### Q2: 国内访问速度慢怎么办？

**A:** 优化建议：

1. **选择国内访问友好的平台**
   - Cloudflare Pages（推荐）
   - 自有服务器（国内云）

2. **使用 CDN**
   - Cloudflare CDN
   - 阿里云 CDN
   - 腾讯云 CDN

3. **代码优化**
   - 减少资源体积
   - 启用 gzip 压缩
   - 使用图片懒加载

---

### Q4: 部署后登录密码不生效？

**A:** 检查：

1. **浏览器缓存**
   - 清除浏览器缓存
   - 或使用无痕模式测试

2. **localStorage 数据**
   - 打开开发者工具 → Application → Local Storage
   - 清除相关数据

3. **代码是否已部署**
   - 确认构建成功
   - 等待部署完成

---

### Q5: 如何配置自定义域名？

**A:** 详见上方"域名配置"章节。简单步骤：

1. 购买域名
2. 在部署平台添加自定义域名
3. 配置 DNS 记录
4. 等待生效（通常几分钟到24小时）

### Q6: 部署后样式丢失怎么办？

**A:** 检查：

1. **构建是否成功**
   ```bash
   npm run build
   # 检查 dist 目录是否有 CSS 文件
   ```

2. **路径问题**
   - 确保 Vite 配置正确
   - 检查 base 路径设置

3. **部署配置**
   - 确保上传的是 dist 目录
   - 不是源代码目录
