## 应用简介

《城市测试》是一款基于五行八字分析和性格测试的城市推荐应用。通过输入出生日期和回答一系列问题，系统会为您智能推荐最适合居住的城市。

### 主要特点

- 🔐 私密访问，密码保护
- ⚗️ 传统五行八字分析
- 📝 10道精心设计的性格测试题目
- 🏙️ 智能城市推荐算法
- 📱 支持手机和电脑访问

## 快速开始

### 方式一：在线访问

如果您已有部署的在线版本，直接在浏览器中访问网址即可。

### 方式二：本地运行

#### 前置要求

确保您的电脑已安装：
- **Node.js**（版本 14 或更高）
- **npm**（通常随 Node.js 一起安装）

#### 安装步骤

1. 下载或克隆项目代码到本地

2. 打开终端/命令提示符，进入项目目录

3. 安装依赖：
```bash
npm install
```

4. 启动应用：
```bash
npm run dev
```

5. 在浏览器中打开显示的地址（通常是 http://localhost:3000）

## 功能说明

### 1. 登录页

应用采用密码保护机制，确保只有授权用户可以使用。

**使用方法：**
- 在输入框中输入访问密码
- 点击"进入测试"按钮
- 密码正确后自动跳转到下一页

**注意事项：**
- 默认密码为 `123456`
- 密码错误会提示"密码错误，请重试"
- 登录成功后会自动保存登录状态

---

### 2. 五行分析页

根据您的出生日期计算八字和五行属性，为城市推荐提供重要依据。

**使用方法：**
1. 点击日期选择器
2. 选择您的出生日期
3. 系统自动计算并显示：
   - 八字（年、月、日、时天干地支）
   - 生肖
   - 五行属性统计
   - 主导五行
4. 确认无误后点击"开始答题"

**名词解释：**
- **八字**：由年、月、日、时的天干地支组成，共八个字
- **五行**：金、木、水、火、土五种元素
- **主导五行**：在您八字中数量最多的五行元素
- **缺失五行**：在您八字中没有出现的五行元素

---

### 3. 答题页

通过回答10道问题，系统了解您的性格偏好和生活需求。

**使用方法：**
1. 阅读题目和选项
2. 点击选择最符合您想法的选项
3. 点击"下一题"继续
4. 最后一题点击"查看结果"

**题目类型：**
- 气候偏好
- 生活节奏
- 城市期待
- 周末活动
- 成本接受度
- 社交环境
- 美食态度
- 教育资源
- 交通要求
- 生活氛围

**进度保存：**
- 答题进度会自动保存
- 意外关闭后重新打开可继续答题
- 返回会清空当前进度

---

### 4. 结果页

系统根据五行分析和答题结果，为您推荐最适合居住的城市。

**结果显示内容：**

#### 🏆 最适合的城市
- 城市名称和图标
- 匹配度分数
- 气候特点
- 城市介绍
- 城市优势
- 注意事项
- 匹配因素说明

#### 🌟 其他推荐城市
- 前6名其他推荐城市
- 每个城市的匹配度分数
- 点击可查看更多城市信息

#### ⚗️ 五行信息回顾
- 显示您的八字
- 主导五行属性

#### 📤 分享结果
- 点击"分享结果"按钮
- 可将结果分享给朋友
- 支持系统分享或复制文本

## 常见问题

### Q1: 忘记密码怎么办？

**A:** 联系管理员获取密码，或查看项目配置文件 `src/data/config.js` 中的密码设置。

---

### Q2: 输入的出生日期会影响结果吗？

**A:** 会的。出生日期用于计算五行属性，这是推荐算法的重要组成部分。五行属性会与城市特征进行匹配计算，从而影响推荐结果。

---

### Q3: 可以重新测试吗？

**A:** 可以。点击结果页的"重新测试"按钮，或清除浏览器数据后重新开始。重新测试会清除之前的答题记录。

---

### Q4: 答题中途可以暂停吗？

**A:** 目前版本不支持暂停功能，但答题进度会自动保存。如果您关闭浏览器，下次打开时可以从中断的地方继续答题。但返回上一页会清空当前进度。

---

### Q5: 推荐结果是固定的吗？

**A:** 不是。推荐结果基于您的输入动态计算，相同的输入会得到相同的结果。如果您更换不同的选项组合，推荐的城市也会发生变化。

---

### Q6: 如何分享结果给朋友？

**A:** 在结果页点击"分享结果"按钮，系统会生成一段文本。您可以选择系统分享功能，或手动复制文本发送给朋友。

---

### Q7: 手机可以使用吗？

**A:** 可以。应用采用响应式设计，完美适配手机、平板和电脑等设备。

---

### Q8: 为什么我的五行有"缺失"？

**A:** 八字由天干地支组成，共八个字，每个字对应一种五行。如果在八字中没有出现某种五行，就会被标记为"缺失"。这是正常现象，缺失的五行可能代表您需要补充的元素。

---

### Q9: 匹配度分数代表什么？

**A:** 匹配度分数表示该城市与您的匹配程度，分数越高表示越适合您。分数综合考虑了答题选择和五行属性的匹配情况。

---

### Q10: 推荐的城市有地理位置限制吗？

**A:** 没有。应用推荐的城市范围覆盖中国各主要城市，不限具体地理位置。推荐完全基于您的个人偏好和五行属性。

---

### Q11: 如何修改个人信息？

**A:** 如需修改出生日期或重新答题，请点击"重新测试"按钮。

---

### Q12: 答题时可以修改已选择的答案吗？

**A:** 可以。在点击"下一题"之前，您随时可以更改当前题目的选项。但一旦进入下一题，就不能再修改之前的答案。
